# בונים דלת — דלתות מגן

מגדיר דלתות: הלקוח עובר שמונה שלבים — מבנה, משקוף, צבע, עיצוב החזית, חלון,
ידית משיכה, מנעול ופרזול — רואה את הדלת משתנה בזמן אמת ואת המחיר המלא, ושולח
לפרץ הודעת וואטסאפ עם הדלת המדויקת שבחר. אין שרת ואין התקנה — זה קובץ HTML אחד.

**האתר בשלוש שפות** — עברית, אנגלית ורוסית. הבחירה נשמרת במכשיר, ואפשר גם
`?lang=ru` בקישור. **ההודעה שנשלחת לפרץ תמיד בעברית**, עם שורה שמספרת באיזו
שפה הלקוח בנה את הדלת, כדי שיֵדע באיזו שפה לחזור אליו.

> **המחירים אמיתיים.** פרץ מסר אותם ב‑26.8.2026, והם מפורטים ב‑`js/prices.js`
> — מסך אחד של שקלים. אפשר ללחוץ על המחיר באתר ולראות ממה הוא מורכב.
> מה שעדיין פתוח מרוכז ב‑`ASK-PERETZ.md`, שהוא 89 שורות ולא 776.

## לפתוח את האתר — שלוש דרכים

### 1. בלחיצה על הקישור (הכי פשוט)

אם GitHub Pages מופעל על המאגר, הכתובת היא
`https://<שם-המשתמש>.github.io/doorproject/`.

להפעיל: **Settings → Pages → Source: Deploy from a branch**, ולבחור את הענף
`claude/door-builder-website-plan-rgg7gu` ותיקייה `/ (root)`. הקובץ `.nojekyll`
כבר במאגר, וצריך אותו — בלעדיו GitHub מתעלם מתיקיות שמתחילות בקו תחתון.

### 2. להוריד ולפתוח בלחיצה כפולה — עובד גם בלי אינטרנט ⭐

זו הדרך להראות את הדלת ללקוח בסלון שלו, או לפרץ במחסן.

1. ב-GitHub: **Code ▾ → Download ZIP**
2. לחלץ את הקובץ
3. **ללחוץ פעמיים על `index.html`**

זהו. לא צריך שרת, לא צריך `npm install`, לא צריך אינטרנט.

> ⚠ ה-ZIP המלא הוא כ-184MB, כי המאגר כולל 129 תמונות של עבודות ואת כל
> גיליונות ההשוואה. **האתר עצמו הוא 733KB על הדיסק, וכ-284KB במעבר ברשת**
> (המספר שהיה כאן, 286KB, נמדד לפני שני סבבים ותיאר אתר קטן יותר).
> אם רוצים רק את האתר, מספיקים ארבעת הקבצים האלה, באותו מבנה תיקיות:
>
> ```
> index.html
> css/app.css
> assets/bundle.js
> assets/room.webp
> ```
>
> אפשר להעתיק אותם לתיקייה, לשלוח בוואטסאפ, לשים על דיסק־און־קי — ולפתוח
> בלחיצה כפולה בכל מחשב.
>
> ⚠ **הרביעי הוא היחיד שאפשר לוותר עליו.** `assets/room.webp` (82KB) הוא
> התצלום של החדר שהדלת עומדת בו. בלעדיו האתר עובד בדיוק אותו דבר, והדלת
> עומדת בחדר המצויר שה-SVG מכיל בעצמו — קיר, רצפה ושתי מנורות. אין הודעת
> שגיאה ואין מקום ריק: הדף לא יודע שחסר לו משהו. השלושה הראשונים הם האתר;
> הרביעי הוא התפאורה.

### 3. `git clone`, למי שמפתח

```bash
git clone https://github.com/yakovef/doorproject.git
cd doorproject
open index.html          # macOS  ·  Windows: start index.html  ·  Linux: xdg-open
```

`npm install` נחוץ **רק** כדי להריץ את הבדיקות והכלים, לא כדי לפתוח את האתר.

## למה זה עובד מקובץ מקומי

זה לא מקרי — זה דרישה מהיום הראשון, כדי שפרץ יוכל לפתוח את התיקייה במחשב
שלו בלי שום דבר מותקן. דפדפנים חוסמים `type="module"` מעל `file://`, ולכן
`tools/build.mjs` מאחד את כל המודולים לסקריפט קלאסי אחד, `assets/bundle.js`,
שמגיע מוכן במאגר.

**מכאן נובע דבר אחד שחשוב לזכור:** אחרי כל שינוי ב-`js/` צריך להריץ
`npm run build`, אחרת האתר שנפתח הוא הגרסה הקודמת. `npm test` תופס את זה,
וגם כל כלי דפדפן — `tools/fresh.mjs` בונה מחדש לבד ואומר שהוא עשה את זה.

## פיתוח

```bash
npm install
npm run build     # מרכיב את assets/bundle.js ומטביע חותם גרסה ב-index.html
npm run dev       # אותו דבר, עם מעקב אחרי שינויים
```

### הכלים — כולם צריכים להיות ירוקים לפני push

| פקודה | מה היא בודקת |
|---|---|
| `npm test` | טענות ברמת המחרוזת: מחיר, קוד, קישור, חוקים, ציור — הכלי מדפיס בעצמו כמה |
| `npm run audit` | הדף האמיתי בכל גודל מסך שמופיע ב-`VIEWS` — קליקים, מקלדת, גרירה |
| `npm run fuzz` | צירופים אקראיים, ואז הליכות קליקים בדפדפן אמיתי |
| `npm run collide` | חומרה שלא מתנגשת · `-- all` · `-- boxes` |
| `npm run profile` | איך האור נופל על הדלת, מול התצלומים |
| `npm run corpus` | שחזור כל 30 הדלתות המדודות מהרשומות שלהן |
| `npm run recreate` | עשר השוואות: תצלום משמאל, שלנו מימין |
| `npm run latency` | כמה זמן לוקחת נגיעה במסך, במעבד מואט פי 6 — מול תקרה של 600 מ״ש |
| `npm run sheets` | מרענן את כל גיליונות ההשוואה אחרי שינוי בציור |
| `npm run backdrop` | בונה מחדש את `assets/room.webp` מהתצלום המקורי שב-`research/backdrops/` |

⚠ **בחלק מהמכונות Chromium מפסיק להצליח לרסטר את הדף בכלל**, והתקרה יורדת ככל
שהמכונה חיה יותר: במדידה אחת 834×1112 עבר בהתחלה, 1099×720 עבר פעם אחת ונפל
עשרים דקות אחר כך, 1280×720 לא עבר אף פעם, ובסוף גם חיתוך של 620×1000 לא חזר.
במצב הזה `npm run sheets` ו-`npm run audit` לא יסתיימו.
`tools/browser.mjs` מקים את הדפדפן מחדש אחרי כל קריסה ומודד שוב, ומדפיס כל
הקמה כזו כדי שריצה שנפלה שש פעמים לא תיראה כמו ריצה שקטה. אם `npm test` מדווח
שארבעת גיליונות ההשוואה ישנים — זה נכון, וזה מה שקורה. ראו `AGENT.md`.
